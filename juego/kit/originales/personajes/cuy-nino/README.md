# El cuy del niño (prueba con el cuy de Joshua, 28 de noviembre)

- `cuy-nino-pedidos.txt`: lo que se le pidió a la herramienta de imágenes para las 7 tiras del cuy de la app sin prendas.
- `prendas-pedidos.txt`: lo que se le pidió para vestir esas tiras con la gorra nube, los lentes cuadrados y el polerón menta.
- `preparacion/` (no se sube): las tiras que entregó. La hoja del juego se arma con
  `node kit/herramientas/armar_protagonista.mjs <carpeta> kit/recursos/dibujos/personajes/cuy-nino.png`, y cada prenda se
  saca comparando la tira vestida con la base (lo que se pinta y lo que tapa).
